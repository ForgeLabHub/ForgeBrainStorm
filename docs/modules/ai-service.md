# Модуль: AI-клиент (GigaChat)

## 1. Назначение и границы
Опциональная генерация вопросов и подсказок через GigaChat. Без ключа модуль
выключен и используется офлайн-банк вопросов.
Не делает: не является обязательным путём игры; не хранит секреты в коде.

## 2. Сценарии использования
- Запрос вопросов по теме кампании.
- Подсказка игроку.
- Отказ: ключ не задан или провайдер недоступен → офлайн-банк или честная ошибка.

## 3. Контракт
Внутренний: `app/ai_client.py`, `app/services/ai_client.py`. Наружу — через игровые
маршруты; прямого публичного API у модуля нет.

## 4. Данные
Собственных таблиц нет. Сгенерированные UGC-вопросы сохраняются сервисом UGC
в `user_data.db` (после валидации).

## 5. Права
Вызов доступен только через игровые сценарии; пользователь не может передать
произвольный промпт на сервер.

## 6. Зависимости
Исходящие: GigaChat API (HTTP, TLS), `gigachat` SDK. Входящие: `game_logic`,
`http_api/*`.

## 7. Конфигурация
`GIGACHAT_CLIENT_ID`, `GIGACHAT_CREDENTIALS` (base64 `client_id:client_secret`),
`GIGACHAT_MODEL`, `GIGACHAT_SCOPE`. Пустой `GIGACHAT_CREDENTIALS` = режим без AI.

## 8. Сборка и отладка
```bash
python -m pytest tests/test_ai_client.py -q
```

## 9. Тесты
`tests/test_ai_client.py`: работа без ключа (офлайн-режим), обработка ошибок
провайдера, отсутствие секретов в логах и ответах.

## 10. Наблюдаемость
Логи запросов без содержимого ключей; ошибки провайдера не валят игру.
Ошибки: `ai_disabled`, `ai_unavailable`.

## 11. Ограничения и готовность
- Качество генерации не гарантируется; вопросы проходят валидацию.
- Нет кэширования ответов модели.
- Готовность: без ключа игра полностью работоспособна (проверяется в CI).
