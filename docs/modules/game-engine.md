# Модуль: игровой движок

## 1. Назначение и границы
Правила игры: генерация раундов, проверка ответов, начисление очков, режимы
(классика, обучение, кампания). Домен без Flask и сети.
Не делает: не отправляет события клиентам (это `realtime`) и не хранит рейтинг
(это `services.leaderboard`).

## 2. Сценарии использования
- Старт раунда: набор вопросов из банка, ограничение по времени.
- Ответ игрока: проверка, начисление очков, фиксация результата.
- Окончание раунда: подсчёт итогов и передача их в лидерборд.
- Отказ: вопросов не хватает → ошибка конфигурации раунда, а не пустой раунд.

## 3. Контракт
Внутренние функции `app/game_logic.py` и `app/domain/*`; наружу выходят события
Socket.IO и ответы `/api/*`. Коды ошибок — `app/errors.py`.

## 4. Данные
Читает банк вопросов (встроенный/офлайн или сгенерированный AI), пишет результат
раунда через сервис лидерборда. Собственных таблиц не имеет.

## 5. Права
Игровые действия доступны анонимно; режим «чит» (`/api/cheat`) требует
`CHEAT_TESTER_CODE` и проверяется отдельно (`tests/test_privileged.py`).

## 6. Зависимости
Исходящие: `app/domain`, `app/ai_client` (генерация вопросов, опционально).
Входящие: `app/http_api/rooms.py`, `app/realtime/socket_events.py`.

## 7. Конфигурация
`CHEAT_TESTER_CODE` (доступ к тестовому режиму). Количество вопросов и время раунда
задаются в данных комнаты.

## 8. Сборка и отладка
```bash
make test
python -m pytest tests/test_domain.py tests/test_services.py -q
```

## 9. Тесты
`tests/test_domain.py` (правила и подсчёт), `tests/test_services.py`,
`tests/test_validation.py` (границы входа), `tests/test_privileged.py` (доступ к
привилегированным действиям).

## 10. Наблюдаемость
Логи раундов и ошибок генерации; состояние комнат видно через Socket.IO-события.
Ошибки: `invalid_answer`, `round_not_ready`, `privileged_required`.

## 11. Ограничения и готовность
- Правила живут в одном процессе: несколько реплик не разделят состояние комнат.
- Нет сохранения промежуточного состояния раунда: рестарт обрывает игру.
- Готовность: правила покрыты unit-тестами; привилегированный режим закрыт кодом.
