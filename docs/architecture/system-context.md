# Контекст системы

## Что это

BrainStorm — веб-игра/квиз с комнатами, рейтингом, режимом обучения, кампаниями,
UGC-вопросами и подсказками от AI (опционально). Один процесс Flask + Socket.IO,
данные — SQLite в каталоге `DATA_DIR`.

## Контекстная диаграмма

```
   ┌────────────┐   ┌──────────────────┐   ┌────────────────────┐
   │ Игрок      │   │ Ведущий/админ    │   │ Telegram/Min App   │
   │ (браузер)  │   │ (браузер+код)    │   │ (опционально)      │
   └─────┬──────┘   └────────┬─────────┘   └─────────┬──────────┘
         │ HTTP/WebSocket    │                       │
         └─────────┬─────────┴───────────┬───────────┘
                   ▼                     ▼
        ┌────────────────────────────────────────────┐
        │ Flask + Flask-SocketIO (gunicorn/eventlet) │
        │  app/domain      правила игры и модели     │
        │  app/http_api    HTTP-маршруты             │
        │  app/realtime    комнаты, чат, планировщик │
        │  app/services    аккаунты, кампании, UGC…  │
        └───────┬───────────────────────┬────────────┘
                │                       │ опционально
                ▼                       ▼
        ┌───────────────┐        ┌──────────────────┐
        │ SQLite        │        │ GigaChat API     │
        │ leaderboard.db│        │ (вопросы, подсказ)│
        │ user_data.db  │        └──────────────────┘
        └───────────────┘
```

## Границы модулей

| Слой | Каталог | Ответственность |
| --- | --- | --- |
| Домен | `app/domain/` | модели, реестр, правила игры — без Flask и сети |
| HTTP | `app/http_api/` | маршруты, валидация, права |
| Реальное время | `app/realtime/` | комнаты, чат, планировщик раундов |
| Сервисы | `app/services/` | аккаунты, достижения, кампании, лидерборд, UGC |
| Хранение | `app/db.py`, `app/user_db.py` | SQLite, схема, WAL, идемпотентные миграции |
| Внешнее | `app/ai_client.py` | GigaChat; при отсутствии ключа — офлайн-банк вопросов |

Правило: домен не импортирует Flask, `http_api` не содержит правил игры.

## Режим отказа внешних систем

| Зависимость | Обязательна | При отсутствии |
| --- | --- | --- |
| Файловая система (`DATA_DIR`) | да | приложение не сможет хранить данные |
| GigaChat | нет | работает офлайн-банк вопросов |
| eventlet | нет | `SOCKETIO_ASYNC_MODE=threading` |

## Границы поддержки

Заявлено: Python 3.12, Linux + Docker/Compose, браузер с WebSocket.
Не заявлено: несколько инстансов на общей SQLite, кластерная работа реального
времени (комнаты живут в памяти процесса), другие СУБД.
