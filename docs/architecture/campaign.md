# Маяк Новой Гавани: одиночная кампания

Маяк хранит память Новой Гавани. В полночь он гаснет, и ученик архивариуса получает компас, в котором звучит голос Лиры. Чтобы вернуть свет, нужно не просто собрать три ключа: придётся понять, почему Маяк отключили и кто должен распоряжаться памятью города.

## Как играть

1. Откройте главную страницу Flask-версии и нажмите **«Маяк Новой Гавани · Играть одному»**. Гость может осмотреть карту; для игры и сохранения нужен аккаунт.
2. Выберите незапертую главу, прочитайте вводную и начните испытание. Друзья, игровая комната и таймер не нужны. После ответа прочитайте объяснение и нажмите **«Продолжить»**.
3. При результате от 40%, 65% и 90% начисляются соответственно одна, две и три звезды. Хотя бы одна звезда открывает эпилог главы. Следующие главы открываются по общему количеству лучших звёзд; повторное прохождение может улучшить результат.

| Акт | Главы | Сюжетный поворот |
| --- | --- | --- |
| I. Погасший архив | Ночной сигнал → Зал хронологии → Оранжерея под стеклом → Страж Архива | Страж отдаёт Ключ Памяти: Маяк отключили намеренно. |
| II. Карта живого города | Кинотеатр без звука → Эстафета на площади → Карта на воде → Радиомастерская → Хранитель маршрутов | Лира остановила Маяк, когда он начал стирать воспоминания. Ключ Связи открывает башню. |
| III. Сердце Маяка | Зал имён → Последняя страница → Рассвет над Новой Гаванью | Ключ Выбора помогает зажечь свет, не возвращая Маяку власть над памятью. |

## Где что находится

| Слой | Путь | Ответственность |
| --- | --- | --- |
| Домен | `app/domain/campaign_catalog.py` | Акт, вводная, эпилог и правила каждой главы; без HTTP, БД и запросов к ИИ. |
| Прикладной сервис | `app/services/campaign.py` | Звёзды, прогресс и награды через SQLite. |
| HTTP | `app/http_api/campaign_routes.py` | Сессия, доступ к главам, генерация вопросов и JSON. |
| Представление | `templates/partials/campaign.html`, `static/js/game.js` | Карта, чтение, ответы и итог; сюжет приходит из каталога. |

Идентификаторы 1–12, темы, пороги и параметры существующих уровней сохранены: старый прогресс не требует миграции. `GET /api/campaign/levels` отдаёт карту, `POST /api/campaign/start` — вопросы открытой главы, `POST /api/campaign/result` — сохраняет результат. Генератор использует настроенный ИИ либо существующий резервный банк. Сюжет фиксированный; набор вопросов может меняться.

## Границы реализации и проверка

Кампания доступна в Flask-версии. Rust и SvelteKit не получают этот сценарий автоматически: перенос потребует отдельного API и миграции данных. Старый API результата принимает итог от клиента, поэтому его нельзя считать источником проверенных результатов для соревнований. Для этого нужен серверный протокол попыток с проверкой ответов и защитой от повторной отправки. Незавершённая попытка не восстанавливается после перезагрузки.

`pytest -q tests/test_api.py` проверяет HTTP и старт главы; `node --check static/js/game.js` проверяет синтаксис клиента. Для ручной проверки: гость → вход → карта → первая глава → ответы и итог → карта с сохранёнными звёздами. Для контекста: [карта архитектуры](overview.md).
