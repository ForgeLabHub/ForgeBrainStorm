# Игровые режимы

ForgeBrainStorm поддерживает множество игровых режимов для разных сценариев использования.

## Доступные режимы

### Классика (Classic)
Все игроки отвечают на одни и те же вопросы одновременно.

**Особенности:**
- Синхронная игра
- Одинаковые вопросы для всех
- Подсчёт очков по скорости и правильности
- Идеально для больших групп

**Использование:**
```json
{
  "mode": "classic",
  "topic": "Общие знания",
  "num_questions": 10
}
```

### Каждый за себя (FFA - Free For All)
Каждый игрок соревнуется индивидуально. Кто быстрее ответит правильно, получает больше очков.

**Особенности:**
- Индивидуальное соревнование
- Приоритет скорости
- Динамичный геймплей
- Подходит для быстрых игр

**Использование:**
```json
{
  "mode": "ffa",
  "topic": "Наука",
  "num_questions": 15
}
```

### Команды (Team)
Игроки делятся на команды и соревнуются вместе.

**Особенности:**
- Командная игра
- Совместный подсчёт очков
- Стратегическое взаимодействие
- Отлично для тимбилдинга

**Использование:**
```json
{
  "mode": "team",
  "topic": "История",
  "num_questions": 20
}
```

### На выживание (Lives)
У каждого игрока 3 жизни. Неправильный ответ отнимает жизнь. Последний выживший побеждает.

**Особенности:**
- Система жизней (3 жизни)
- Постепенное выбывание
- Напряжение до конца
- Идеально для чемпионатов

**Использование:**
```json
{
  "mode": "lives",
  "topic": "География",
  "num_questions": 30
}
```

### Кооператив (Cooperative)
Все игроки работают вместе, чтобы ответить на как можно больше вопросов.

**Особенности:**
- Совместная игра против системы
- Общий счёт
- Коллективное обсуждение
- Подходит для обучения

**Использование:**
```json
{
  "mode": "coop",
  "topic": "Литература",
  "num_questions": 25
}
```

### Своя Игра (Svojaigra)
Jeopardy-стиль: игроки выбирают вопросы из категорий с разными очками.

**Особенности:**
- Выбор вопросов
- Разные категории
- Стратегия выбора очков
- Глубокий геймплей

**Использование:**
```json
{
  "mode": "svoyaigra",
  "topic": "Разные темы",
  "num_questions": 30
}
```

## Настройка режима

Режим устанавливается при создании комнаты:

```rust
let settings = RoomSettings {
    mode: "classic".into(),
    topic: "Общие знания".into(),
    num_questions: 10,
    num_options: 4,
    timer_secs: 30,
    difficulty: "medium".into(),
    ai_provider: Some("ollama".into()),
    ai_model: None,
};
```

## Динамическая сложность

Все режимы поддерживают автоматическую адаптацию сложности через систему DDA (Dynamic Difficulty Adjustment).

Смотрите: [Динамическая адаптация сложности](dynamic_difficulty_adjustment.md)

## Генерация вопросов с RAG

Все режимы могут использовать RAG (Retrieval-Augmented Generation) для создания вопросов на основе пользовательских документов.

Смотрите: [Retrieval-Augmented Generation](retrieval_augmented_generation.md)

## API эндпоинты

### Создание комнаты с режимом

```http
POST /api/room/create
Content-Type: application/json

{
  "mode": "ffa",
  "topic": "Технологии",
  "num_questions": 15,
  "difficulty": "hard"
}
```

### Список комнат

```http
GET /api/rooms
```

Ответ:
```json
{
  "rooms": [
    {
      "code": "ABC123",
      "mode": "ffa",
      "topic": "Технологии",
      "players": 5,
      "max_players": 10
    }
  ]
}
```

## Рекомендации по выбору режима

| Сценарий | Рекомендуемый режим | Почему |
|----------|---------------------|--------|
| Быстрая игра | FFA | Минимум времени на настройку |
| Тимбилдинг | Team | Развивает сотрудничество |
| Обучение | Cooperative | Совместное обсуждение |
| Соревнование | Lives | Высокое напряжение |
| Глубокая игра | Svoyaigra | Стратегический выбор |
| Большая группа | Classic | Простота и масштаб |

## Производительность

Все режимы оптимизированы для:
- Мобильных устройств
- Низкой задержки WebSocket
- Плавных анимаций
- Минимального потребления батареи

Смотрите: [Оптимизация производительности](../performance.md)
