## 🐛 Исправленные проблемы (из отчёта OpenHands)

### Rust backend

1. **`[env]` в `config/default.toml`** — лишняя TOML-секция. Все поля были внутри `[env]`, что ломало Figment. Убрал, все поля на top-level.

2. **`api_key = null` в TOML** — TOML не поддерживает `null`. Заменил на `api_key = ""`.

3. **`Figment::nested()` вызов** — этот метод для TOML с вложенными секциями вида `[section.key]`. У нас все ключи top-level, поэтому `.nested()` вызывал проблемы. Убрал вызов, оставил просто `Toml::file("config/default.toml")`.

4. **`Env::raw().only(...)` API** — в новых версиях figment этот API устарел. Убрал, оставил только `Env::prefixed("BRAINSTORM_")`.

5. **`CREATE EXTENSION citext` отсутствует** — миграция использовала тип `CITEXT` (case-insensitive text), но расширение не создавалось. Добавил `CREATE EXTENSION IF NOT EXISTS citext;` в начало миграции.

6. **CORS: `credentials + *`** — когда список origins пустой, код ставил `AllowOrigin::default()` (Any) + `allow_credentials(true)`. Это несовместимо по спецификации CORS, браузеры отвергают такой ответ. Разделил логику: если origins пустые — credentials отключены; если есть origins — credentials включены.

7. **`POST /api/rooms` не имел auth-middleware** — endpoint `create_room` ожидал `AuthContext`, но middleware не был навешен. Разделил роутер на `public` (GET) и `protected` (POST с auth-middleware).

### Docker

8. **Rust 1.80 слишком старый** — обновил до `rust:1.85-slim`.

9. **`curl` отсутствует в slim-образе** — добавил установку curl в runtime-образе.

### Frontend

10. **Невалидный Svelte синтаксис `class:`** — 7 мест в `room/create/+page.svelte` использовали `class: border-blue-500 bg-blue-500/10={expr}`, что не работает в Svelte. Переписал через комбинацию тернарного оператора и одиночного `class:border-blue-500={expr}`.

11. **Отсутствовали конфигурационные файлы** — добавил:
    - `tailwind.config.js`
    - `postcss.config.js`
    - `tsconfig.json`
    Без них Tailwind не работал, и страницы рендерились без стилей.

12. **`RoomSnapshot.host_name` vs frontend `host`** — в Rust поле называлось `host_name`, а на фронтенде ожидалось `host`. Добавил `#[serde(rename = "host")]` в Rust.
