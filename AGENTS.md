# Правила для ИИ-агентов (OpenHands и другие)

1. **Одна задача за раз.** Делай минимальное законченное изменение. Не совмещай исправление сборки с рефакторингом, миграцией или новой функциональностью.
2. **Ограничивай контекст.** Начинай с `git status --short`, `rg --files` и поиска по символам через `rg`. Читай только нужные модули и тесты.
3. **Проверяй каждое изменение Rust.** Из `rust-server/` запусти `cargo check --all-targets` и `cargo clippy --all-targets -- -D warnings`. Перед завершением запусти `make agent-verify` из корня. Не отключай предупреждения, чтобы добиться зелёного статуса.
4. **Покрывай изменения логики тестами.** Добавь или обнови тест рядом с изменённым кодом. В рабочем коде обрабатывай ожидаемые ошибки через `Result` и `?`, а не через `unwrap()` или `expect()`.
5. **Не зацикливайся.** После трёх неудачных попыток исправить сборку остановись и сообщи команду, конкретную ошибку и следующий шаг. При необходимости откатывай только собственные правки, сохраняя изменения пользователя. Не используй `git checkout -- .` или `git reset --hard`. Если отсутствует инструмент или зависимость, сообщи о блокировке, а не меняй код наугад.
